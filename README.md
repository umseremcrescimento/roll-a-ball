## Sobre o projeto 
O jogo se baseia no jogador controlar uma bola utilizar as físicas da bola, para conseguir passar por obstaculos e conseguir pegar todos os pontos sendo representados por quadrados.
## O que o projeto faz 
- o jogador movimenta a bolinha com WASD
- ao encostar nos itens, eles somem e o placar aumenta
- quando coleta tudo, aparece a mensagem de vitória
- se o jogador cair para fora do mapa o jogo trava.
## O que o projeto contém 
**Cenas:** nenhuma
**Scripts:** Camera: faz a camera seguir o jogador; Chaomorte: faz o jogo parar quando o jogador cai no objeto com o codigo; Coletavel: Permite que o objeto suma depois do jogador tocar e adicionar pontos para a pontuação;
Gerenciador: um contabilizador para contar os pontos que o jogador pega para vencer o jogo e fazer o bloco que vale 5 pontos funcionar; Player_controler: fazer o jogador poder andar; reset: tentiva falha de fazer o jogador conseguir resetar o jogo;
Rotation: Fazer algum girar (coletáveis).
**Objetos principais:** Sphere (3), PickUp, Goat e Plane.
**Recursos usados:** Rigidbody, Collider com Is trigger e sem e TextMeshPro
## Controles 
WASD – Faz o jogador poder andar para frente, para tras, esquerda e direita.
